# Shared Odin Libraries

A collection of libraries I commonly used. Please see the related libraries README for details surrounding library info.

These libraries are intended to be added directly to Odin's 'shared' folder.

### Current Libraries
* `zip`: A simple ZIP read/write library.
* `log`: A simple logging library inspired by Raylib's `TraceLog(...)` functions.
* `debug`: Some simple debug utilities like a tracking allocator, scoped timers, etc.
